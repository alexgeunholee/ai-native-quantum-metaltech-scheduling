# Publish the prepared repository (no coding required)

## Recommended: GitHub Desktop
1. Extract the ZIP downloaded from ChatGPT; you should see a single `AI_Native_Quantum_GitHub_Repository` folder containing `README.md`, `LICENSE`, the two `schedule_*.json` files, `notebooks/`, `evidence/`, etc.
2. Install/open **GitHub Desktop** from <https://desktop.github.com/> and sign in to your GitHub account.
3. Select **File → Add local repository → Choose…** and select the extracted folder. If offered **Create a Repository Here**, accept, set name `ai-native-quantum-metaltech-scheduling` and choose Git ignore=None/License=None because this folder already contains `.gitignore` and `LICENSE`.
4. Set the commit summary to `Initial QPoland 2026 seven-stage scheduling submission` and click **Commit to main**.
5. Select **Publish repository**. **Uncheck** `Keep this code private` so the repository is **PUBLIC**, confirm the repository name and publish.
6. Open the repository page in your browser and confirm the root has `README.md`, `LICENSE`, `PROJECT_DESIGN.md`, `DEVELOPMENT_LOG.md`, `schedule_2x2.json` and `schedule_3x3.json`. Copy the real URL (do not invent one).

## Web alternative
Create **New repository** on <https://github.com/new>, choose `ai-native-quantum-metaltech-scheduling`, visibility **Public**, do not initialize with README/license (already included here). Extract the package and upload its contained files/folders to the created repository using **Add file → Upload files** (folder drag-and-drop support varies by browser). Click **Commit changes** and check that `notebooks/` and `evidence/` actually uploaded. If many files are omitted, prefer GitHub Desktop.
